# Colocar Credenciales De Configuracion De Github

Dirigirse A Arriba Y Buscar El Boton Terminal Y Despues Presionar New Terminal.
Ahora Toca Ingresar Tu Nombre Y Contraseña De Github De Esta Manera
Pegar Ambos Codigos En El Terminal Con Click Derecho Y Presionando Enter Separadamente

Ingresar El Nombre De Usuario De Github

   ```bash
    git config --global user.name "Samuel2015Y11"
   ```

Ingresar El Correo De Github

```bash
   git config --global user.email "edersamuel030@gmail.com"
```

# Inicializar Git

Ir Al Tercer Boton Source Control
Y Presionar Initialize Repository

OBLIGATORIO
Colocar Un Comentario De Que Se Hizo Y Dar Click En Commit
Tambien Iniciar Sesion, Dejar El Autorizo A La Cuenta Y Dar A Publish Branch Dar Al Aviso Yes Y Subir Uno Publico
